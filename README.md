# 💰 ExpenseTrackerPro

A modern expense tracking web application built with Spring Boot.

## ✨ Features

- 🔐 User Authentication (Spring Security)
- 🔒 BCrypt Password Encryption
- 👤 User Registration & Login
- 💸 Expense Management
- 📊 Dashboard
- 🗄️ MySQL Database
- 🎨 Bootstrap UI
- 🌐 Thymeleaf Templates

---

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- Bootstrap 5
- Maven

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/skype-28/ExpenseTrackerPro.git
```

Configure your MySQL database in:

```properties
src/main/resources/application.properties
```

Run the project:

```bash
./mvnw spring-boot:run
```
